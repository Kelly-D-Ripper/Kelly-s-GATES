# Kelly's GATES 0.6.0 — draft

Experimental client-side throttle calibration for Nuclear Option. This build broadens the earlier URSA MINOR mod with manufacturer-independent joystick-axis detection, single- or dual-lever calibration, and an explicit no-analogue-reverse-gate mode. Existing URSA configuration and bindings are retained. F9 also includes the earlier airbrake button/key binding and options.

The earlier URSA airbrake fix was reported as apparently working; **this 0.6.0 build, all other controller models, and multiplayer remain untested in game**. Offline tests cover calibration modes, curves, ownership policies and the currently installed game's hook contracts. See the included README and hardware research list for requirements, limitations and a safe test sequence.
